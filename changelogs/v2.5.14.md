## v2.5.14

Port collision scanner with process occupant detection, desktop app Scan Options popup, Happ/WinINET proxy support, keyring chunking fix for Windows Credential Manager, HttpService discovery concurrency batching, and plugin replacement reliability fixes.

### Fixed
- **Plugin discovery failed on wide port ranges ("Number of requests exceeded limit").** When the scan range was widened beyond ~10 ports, firing all probes concurrently hit Roblox's `HttpService` concurrency cap, causing every request to fail silently and reporting "no desktop app found". Discovery now probes in batches of 8 with early exit, allowing any port range to connect instantly.
- **Keyring secrets exceeded Windows Credential Manager 2560-byte blob limit.** Saving accounts with long cookies or metadata caused Credential Manager writes to fail silently with error 2560. Secrets are now stored in 1000-byte chunked entries and reassembled automatically on load.
- **Happ VPN / System Proxy compatibility.** `reqwest` now reads Windows WinINET system proxy settings (used by Happ VPN in Proxy mode), supports SOCKS proxies, and wires `proxyUrl` to all Roblox API calls.
- **Studio scan stall watchdog false timeouts.** Progress-based watchdog resets whenever the scanned count advances, preventing 5-minute timeout errors on huge places.
- **Cleaned up download error log spam.** Per-candidate URL attempts no longer flood the UI console; concise failure messages clearly explain private, copylocked, or deleted place assets.
- **Plugin MeshPart and property replacement fixes**:
  - MeshPart replacement rebuilds without deleting instances or breaking child connections.
  - Digit frontier matching (`%f[%d]`) prevents accidental substring corruption of asset IDs inside longer numbers.
  - Corrected `__Attribute__:` string slicing for attribute property patches.
  - Wrapped manual replacements in a single ChangeHistory recording for full undo (Ctrl+Z) support.
  - In-place `TextureID` swaps for MeshParts without rebuilding the entire mesh.
  - Automatic `rbxassetid://` URI coercion (`toAssetUriString`).

### Added
- **Scan Options Popup in Desktop App.** Clicking "Scan Studio" opens a modal letting you select which asset types to scan for (Sounds, Animations, Images, Meshes, Scripts) and the Script Scan Mode (*Asset IDs (fast)*, *Full source (accurate)*, or *Off*).
- **Port Collision Scanner with Process Owner Diagnostic.** Binds incrementally across ports 14285–14320 when default ports are occupied, and displays a banner identifying the process (e.g. `Discord.exe`) holding default ports.
- **HttpService Disabled Guard in Plugin.** Detects when "Allow HTTP Requests" is off in Game Settings and displays an actionable warning message instead of a misleading port error.
