## v2.6.1

Major update introducing a native secondary OS preview window with Always-On-Top pinning, Studio-grade Inspector Property Grid, targeted DataModel path scanning, single-child folder compaction, fixed batch metadata resolution, and comprehensive UI polish.

### Added

- **Native Floating Preview Window.** Pop out 2D textures, 3D meshes, and animations into a standalone frameless secondary OS desktop window with Always-On-Top (📌 Pin) support, 0px flush borders, and live asset sync.
- **2D Texture Pan & Zoom.** Scroll wheel zoom (25% to 800%), drag-to-pan, and quick zoom preset dropdowns for textures, decals, and image assets.
- **Studio Property Grid Inspector.** Rebuilt inspector into a Roblox Studio-style Properties Table with expandable "Appearance & Values" and "Instance Details" sections, property copy buttons, and independent Viewport/Properties toggling.
- **Targeted DataModel Path Scanning.** Scan specific sub-trees (e.g. `game.Workspace.Guns`) directly from Studio without crawling the entire game hierarchy.
- **Single-Child Folder Compaction.** Deep linear hierarchies automatically collapse into clean breadcrumb nodes (`Folder / Subfolder / Model`) in the Asset Explorer.
- **Place Name Auto-Discovery.** Studio sessions now display their actual place name (`game.Name`) instead of generic `"Studio Session"` labels.
- **Split Place File Extraction Settings.** Open place files (`.rbxl`/`.rbxlx`) with custom asset category filters via the split `[ Open File | ⚙ ]` button.
- **Unique Settings Icons & Unified Cards.** Distinct Lucide icons for all 9 settings tabs, zero-gap headers, and custom-styled range sliders.

### Fixed

- **Roblox Batch Metadata 0/49 Failures.** Fixed catalog chunking by enforcing Roblox's 30-item limit for `catalog.roblox.com` and adding automatic fallback to `develop.roblox.com/v1/assets` in chunks of 50 for developer assets (animations, private audio).
- **Luau Nil Call Crash on Property Scan.** Fixed `attempt to call a nil value` in `properties.luau` caused by scope hoisting of `isScanTypeEnabled`.
- **Phantom Duplicate Instance Counts.** Eliminated duplicate `2x`/`3x` badges caused by modern Roblox Content properties (`AnimationId` + `AnimationContent`).
- **Tokio Reactor Panic on Cache Clear.** Converted cache purging commands to `async fn` to prevent panics when clearing cache from worker threads.
- **Complete Cache Purging.** "Clear Cache" now wipes Rust backend disk caches, Zustand memory state, and all saved pairings/place IDs in `localStorage`.
- **Selection Count Ballooning.** Folder selection counts now strictly respect active asset category filters.
- **Profile Popup Layout Shift.** Replaced shifting "Loading groups…" text with an inline spinner next to the header.
- **Scrubber Timeline Hover Jitter.** Draggable timeline thumb now stays stable without shifting height on hover.
