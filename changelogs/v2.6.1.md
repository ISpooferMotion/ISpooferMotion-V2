## v2.6.1

### Fixed

- **Per-asset place ID batch resolution.** The batch download URL endpoint now receives each asset's individually discovered Place ID rather than falling back to slow per-asset resolution on multi-universe places.
- **Fast Open Cloud operation polling.** Reduced operation poll intervals with adaptive 200ms initial retries for faster asset publishing.
- **Roblox Catalog batch metadata failures (0/49 results).** Enforced 30-item chunk limit on `catalog.roblox.com/v1/catalog/items/details` with automatic 50-item fallback to `develop.roblox.com/v1/assets` for non-catalog developer assets.
- **Luau scan crash on properties.** Fixed `attempt to call a nil value` in `properties.luau` caused by function declaration hoisting.
- **Phantom duplicate instance counts.** Eliminated duplicate `2x`/`3x` badges caused by modern Roblox Content properties (`AnimationId` + `AnimationContent`).
- **Tokio reactor panic on cache clear.** Converted cache purging commands to `async fn` and ensured `place_id_cache.json`, Zustand memory state, and localStorage keys are fully purged.
- **Selection count on filtered trees.** Folder selection counters now only evaluate visible assets matching active category filters.
- **Profile popup layout shift.** Replaced shifting loading text with an inline spinner next to the header.
- **Scrubber timeline height jumping.** Fixed timeline container sizing in the Animation Preview so hovering the scrubber thumb does not alter height.
- **Plugin UI responsiveness.** Added periodic cooperative yields (`task.wait()`) during manual replacement sweeps to keep Studio responsive during large-scale operations.
- **Plugin cleanup on exit.** Added automatic plugin uninstallation when closing or quitting the desktop client.

### Added

- **Standalone floating preview window.** Detached frameless OS window with Always-On-Top (pin) support, 0px flush borders, and live IPC asset synchronization.
- **Properties table inspector.** Replaced detail cards with a structured property grid with independent Viewport and Properties panel toggles.
- **2D texture pan & zoom.** Added mouse wheel zoom (25%–800%), drag-to-pan canvas, and preset zoom dropdowns for image assets.
- **Targeted DataModel path scanning.** Added targeted path scanning (`game.Workspace.Model`) in the plugin, daemon, and UI with asset type and script mode options.
- **Single-child folder compaction.** Linear single-child folder chains collapse into breadcrumb paths (`Folder / Subfolder / Model`).
- **Ghost IDs system.** Added standalone asset ID input in `Manual Replace & Add IDs` where missing place assets are tracked as Ghost IDs with a "Save Ghost IDs to Studio" action.
- **Place file extraction options.** Added split `[ Open File | ⚙ ]` button to configure asset category extraction filters when opening `.rbxl` and `.rbxlx` files.
- **Upload Operation Poll Interval slider.** Configurable polling frequency (100ms–1000ms, default 250ms) in Routing and Limits settings.
- **Place name auto-discovery.** Connected Studio sessions automatically display the actual place name (`game.Name`).
- **Console spoofing speed metrics.** Console logs total duration and average throughput per asset upon spoof job completion.
- **Animated sidebar logo.** Added animated WEBP logo in the navigation sidebar header.
- **Settings UI styling.** Unified zero-gap card containers, unique Lucide icons, and custom Tailwind range sliders.
- **Desktop notifications & toasts.** Added notifications and toasts when clearing cache or submitting manual replacement pairs and ghost IDs.
