# ISpooferMotion v2.5.1 (2026-07-19)

## ✨ New Features

- **Smart Asset Filtering:** Re-added support for filtering out assets you already own in the UI, avoiding duplicate spoofing jobs.

## 🐛 Bug Fixes

- **Remote Cache Initialization:** The application now correctly initializes the remote cache push URL when telemetry is enabled in user settings, improving community cache contribution reliability.

## 🛠 Internal / Technical

- **Codebase Cleanups:** Overhauled the IPC job processor, UI components, and codebase formatting for better consistency.
- **Removed Unused Dependencies:** Removed legacy ISM-Library references, initialization scripts, and unused dependencies to improve maintainability.
- **Testing & Linters:** Resolved various lint warnings and flaking state tests in both the frontend (e.g. `AssetExplorer.test.tsx`) and the Rust backend.
